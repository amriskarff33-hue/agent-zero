# Airports

One file per aerodrome you deliver at, named by ICAO code (`FAXX.md`, `FAYY.md`).

Use `00_airport_data_template.md` as the starting point. Every fact must carry a source.
**If a value is not verified, leave it blank** — a blank is honest, a guess is dangerous.

Examples: `FAXX.md`, `FAYY.md`, `aip-ad-2-faxx.pdf`.
